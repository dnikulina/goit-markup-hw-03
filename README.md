## Overview

This version of the WebStudio landing page focuses on layout construction using reusable containers, Flexbox, spacing, and positioning.

## Tech Stack

- HTML5
- CSS3
- Flexbox
- Modern Normalize
- Google Fonts
- Git & GitHub

## Implemented Features

- reusable container structure;
- Flexbox-based header and section layouts;
- aligned navigation and contact blocks;
- multi-column feature, team, and portfolio sections;
- improved spacing and positioning;
- consistent content width across sections.

## Learning Outcomes

- Flexbox layout;
- reusable container patterns;
- element alignment and distribution;
- box model and spacing;
- relative and absolute positioning;
- building structured page layouts from a design.
